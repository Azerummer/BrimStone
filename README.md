# 卡牌肉鸽：灰烬远征

一个纯前端实现的网页卡牌 Roguelike 小游戏（无需构建工具，打开 `index.html` 即可游玩）。

## 玩法说明

- 你有生命值、护甲和每回合 3 点能量。
- 每回合从牌堆抽 5 张牌，打出卡牌来攻击或防御。
- 点 `结束回合` 后，敌人会按“意图”行动。
- 击败敌人后可三选一添加新卡，逐层变强。
- 通关第 6 层即可获胜。

## 运行方式

直接双击 `index.html`，或使用任意静态服务器：

```bash
python3 -m http.server 8000
```

然后访问：<http://localhost:8000>
